## Client Guide

### Getting Started

1. **Registration**
   - Visit the registration page
   - Enter your name, email, and password
   - Or sign up with Google
   - You'll be automatically assigned the CLIENT role

2. **Login**
   - Use your email and password
   - Or click "Sign in with Google"

### Creating a Service Request

1. Navigate to "New Request" from your dashboard
2. Select a service type:
   - App Development
   - Web Development
   - Branding & Creative
3. Fill in the request details:
   - Title
   - Description
   - Requirements
4. Submit the request
5. Wait for admin approval and developer assignment

### Managing Projects

- View all your projects from the dashboard
- Track project progress
- Communicate with developers via messages
- Upload/download project files
- Make payments

### Making Payments

1. Go to Payments section
2. Select the project
3. Enter payment amount
4. Complete payment via Stripe
5. View payment history

## Developer Guide

### Getting Started

1. **Account Setup**
   - Developers are assigned by Admin only
   - You'll receive an email notification when assigned
   - Login with your credentials

2. **Dashboard Overview**
   - View assigned projects
   - Track project status
   - See project progress

### Managing Projects

1. **View Projects**
   - All assigned projects appear on your dashboard
   - Filter by status (planning, in-progress, review, completed)

2. **Update Project Status**
   - Change status as work progresses
   - Update progress percentage
   - Add milestones

3. **Communication**
   - Send messages to clients
   - Respond to client inquiries
   - Share project updates

4. **File Management**
   - Upload project files
   - Organize files by project
   - Share deliverables

## Admin Guide

### Getting Started

1. **Admin Access**
   - Admin accounts are created manually
   - Cannot be created via registration
   - Contact system administrator for access

### User Management

1. **View All Users**
   - Access Users section
   - Filter by role or status
   - View user details

2. **Assign Developer Role**
   - Select a user
   - Change role to "developer"
   - User will receive notification

3. **Manage User Status**
   - Activate/deactivate users
   - Cannot deactivate your own account

### Service Management

1. **Create Services**
   - Add new services to catalog
   - Set base prices
   - Categorize services

2. **Update Services**
   - Edit service details
   - Update pricing
   - Deactivate services

### Service Request Management

1. **View Requests**
   - See all service requests
   - Filter by status
   - View request details

2. **Assign Developers**
   - Select a request
   - Choose a developer
   - Set estimated price
   - Approve request

3. **Create Projects**
   - Convert approved requests to projects
   - Assign developers
   - Set project timeline and budget

### Project Management

1. **Monitor Projects**
   - View all projects
   - Track progress
   - Review milestones

2. **Manage Projects**
   - Update project details
   - Reassign developers
   - Adjust budgets

### Payment Management

1. **View Payments**
   - See all payment transactions
   - Filter by status
   - View payment details

2. **Update Payment Status**
   - Mark payments as completed
   - Process refunds
   - Generate invoices

### System Administration

1. **Audit Logs**
   - View system activity
   - Track user actions
   - Monitor security events

2. **System Statistics**
   - View dashboard metrics
   - Monitor system health
   - Generate reports
